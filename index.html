    使い方

    カメラに映った人の動きから速度を測り、基準を下回ったら音で知らせます。映像はこの端末の中だけで処理され、外部には送られません。

    使える機器

    カメラとブラウザがあれば、どの機器でも使えます。Mac や iPad のカメラでもできます。

    スマホiPhone、Android。背面カメラを使います
    iPad・タブレット背面カメラを使います。画面が大きいので数値が見やすい
    パソコンMac・Windows の内蔵カメラ、または外付けの Web カメラ
    Mac ＋ iPhoneiPhone をカメラにして、Mac の大きな画面で見る

    ブラウザは Safari か Chrome を使ってください。複数のカメラがあるときは「設定」のカメラ欄で切り替えられます。

    準備

    共通

    • カメラを三脚などで固定し、選手の真横に置く
    • 頭から足まで全身が映る距離にする
    • 音量を上げる（アラート音のため）

    スマホ・iPad で使う

    • 横向きにして固定する
    • 消音モードを切る

    パソコンのカメラで使う

    • 画面を選手のほうへ向け、全身が映るまで離れる
    • 内蔵カメラは画面の角度で映り方が変わるので、縮尺を合わせたあとは画面を動かさない

    Mac の画面で見る（iPhone をカメラにする）

    • Mac の Safari でこのページを開く
    • iPhone をロックして横向きに固定し、Mac の近くに置く（同じ Apple ID、Wi-Fi と Bluetooth をオン）
    • カメラ欄に iPhone が出ないときは、iPhone をケーブルで Mac につなぐと安定する

    手順

    1. 「カメラを開始」を押し、カメラの使用を許可する
    2. 左下に「骨格検出：追跡中」と出て、体に白い線が重なることを確かめる
    3. 縮尺を合わせる（どちらか一方）
      • 身長で合わせる：身長を入力して押す。3秒後に測るので、計測する位置にまっすぐ立つ
      • 長さで合わせる：映像の中で、長さがわかるものの両端を2か所タップして長さを入力する。バー種目はプレートの直径（45cm）がおすすめ
    4. モードとアラートの基準を選んで計測する
    5. セットが変わったら「新しいセット」を押す

    選手、カメラの位置、計測する場所が変わったら、縮尺を合わせ直してください。

    アラート

    • 下限速度：設定した m/s を下回ったら鳴る
    • 速度低下率：セット内で最速だった回から、設定した % 以上落ちたら鳴る
      目安：筋力・パワー狙いは 10〜20%、筋肥大狙いは 25% 以上

    種目や選手によって変わる目安です。

    精度について

    • 数値は目安です。専用の VBT 機器と同じ精度ではありません
    • 毎回同じ位置・同じ距離から撮ると、回ごとの比較が安定します
    • カメラに近づく・遠ざかる向きの動きは正しく測れません（真横からの動きだけ）
    • 初回はインターネット接続が必要です（骨格検出の部品を読み込むため）
