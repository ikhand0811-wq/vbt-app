# VBT 速度計測アプリの使い方

## 準備（最初の1回）
- Mac と iPhone で同じ Apple ID にサインインし、両方の Wi-Fi と Bluetooth をオンにする
- iPhone の「設定 → 一般 → AirPlay と連係 → 連係カメラ」をオンにする
- ブラウザは Safari を使う（Chrome では iPhone のカメラが出ないことがある）

## 毎回の手順
1. iPhone を三脚などに**横向きで固定**し、選手の**真横**に置く。頭から足まで映る距離にする
2. `VBTを起動.command` をダブルクリックする（黒いウインドウとブラウザが開く）
3. 「カメラを開始」を押し、カメラの使用を許可する。カメラ欄で iPhone を選ぶ
4. 身長を入力し、選手が計測する位置にまっすぐ立つ。「キャリブレーション」を押すと 3 秒後に測る
5. モード（バー／体）とアラートの基準を選んで計測する
6. セットが変わったら「新しいセット」を押す

終了するときは黒いウインドウを閉じる。

## モード
| | 追う場所 | 主な数値 | 向いている種目 |
|---|---|---|---|
| バー | 両手首の中点 | 1レップの平均速度 | スクワット、ベンチプレス、デッドリフト |
| 体 | 腰の中心 | 1試技の最大速度 | ジャンプ、短い移動 |

## アラート
- **下限速度**：設定した m/s を下回ったら鳴る
- **速度低下率**：セット内で最速だった回から設定した % 以上落ちたら鳴る
  - 目安：筋力・パワー狙いは 10〜20%、筋肥大狙いは 25% 以上

## 速度ゾーン（バーモードの平均速度の目安）
| m/s | 狙い |
|---|---|
| 0.5 未満 | 最大筋力 |
| 0.5–0.75 | 加速筋力 |
| 0.75–1.0 | 筋力スピード |
| 1.0–1.3 | スピード筋力 |
| 1.3 超 | スターティングストレングス |

種目や選手によって変わる目安です。

## 精度について
- 数値は目安です。専用の VBT 機器と同じ精度ではありません
- 毎回同じ位置・同じ距離から撮ると、回ごとの比較が安定します
- 選手、カメラ位置、計測する場所が変わったら、キャリブレーションをやり直してください
- 選手がカメラに近づいたり遠ざかったりする動きは正しく測れません（真横からの動きだけ）
- 初回はインターネット接続が必要です（骨格検出の部品を読み込むため）。映像は外部に送られません
